# developer-ai/05_CHECKLISTS/PR.md


Version: 2.0.0

# Purpose

Complete this checklist before opening or approving a Pull Request.

# Scope

☐ PR addresses one logical change

☐ Unrelated changes removed

☐ Commit history is understandable

# Architecture

☐ Engineering Kit followed

☐ Architecture unchanged OR documentation updated

☐ Patterns followed consistently

# Code Quality

☐ Readable implementation

☐ No dead code

☐ No unnecessary abstraction

☐ Dependency injection used where required

# Security

☐ Secrets externalized

☐ Authorization verified

☐ Validation complete

☐ Sensitive data not logged

# Testing

☐ Existing tests pass

☐ New tests added

☐ Regression tests added

☐ Manual verification completed (if applicable)

# Documentation

☐ Specifications referenced

☐ Documentation updated

☐ Public interfaces documented

# Review

☐ Self-review completed

☐ Critical TODOs resolved

☐ Merge recommendation documented

# Approval

☐ Ready for merge
